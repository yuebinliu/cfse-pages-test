总览技术栈优点

WordPress 静态化 + 自托管 CMS

一个把 WordPress 内容发布到边缘的开源方案：WP 当后台，Cloudflare Workers 当运行时。 单页直读对象存储、列表页实时查库、可选整站全静态 —— 动静自由切换，互不牵制。

它长什么样

浏览器 ──► Cloudflare 边缘（Worker） ├─ 静态资源 → assets（免费无限）→ 未命中落 R2 ├─ 文章单页 → R2 直读；未命中 ⇒ 查 D1 现场渲染并回填（自愈） ├─ 列表/分类/标签/归档 → D1 实时渲染（可 KV 缓存，TTL 0 即直查） └─ 后台 /admin/ + REST /wp-json/wp/v2/* WordPress（内容生产线） └─ 插件钩子：保存文章 → 渲染单页 / 写 D1 / 上传 R2（三项独立开关）

三种模式，随站自由选

① 全动态

只同步数据到 D1，单页与列表都由 Worker 实时渲染。写作即发布，零构建。

② 动静结合

文章单页落 R2（快），列表页查 D1（新）。最常用的形态。

③ 全静态

整站产物可发布到任意静态托管（S3 兼容 / 本地目录 / GitHub Pages…），不依赖运行时。

为什么值得一看

  • 不是"生成器"，是"运行时替换"：列表页永远实时，单页永远静态，各自用最合适的方式。
  • 双后台：WordPress 后台与 Worker 后台互为镜像；从任一侧写，另一侧可对齐。
  • Markdown 原生：Obsidian 等 md 编辑器可通过 /wp-json/wp/v2/* 直连发布，原稿按 md 存储，两端渲染一致。
  • 多托管出口：一份产物，按能力分发到多个目标（对象存储 / 本地 / 自己的 Worker / git 型托管）。
  • 零出站费：R2 → Cloudflare CDN 出站不计费，容量上限由 10GB 存储主导。
